# FantasyTeamGuru – Cricket Intelligence Engine

FantasyTeamGuru is a data-driven cricket analytics and fantasy cricket
platform focused on IPL history, player performance, head-to-head stats,
and season intelligence.

🌐 Official Website:
https://www.fantasyteamguru.com

## Features
- IPL match data (2008–2025)
- Player profiles with career stats
- Head-to-Head team & player analysis
- Season Intelligence (Orange Cap, Purple Cap, Top Performers)
- Fantasy cricket insights & tips

- Seasons: https://www.fantasyteamguru.com/season/

## Tech Stack
- PHP
- MySQL
- HTML, CSS, JavaScript
- JSON-based match data processing
